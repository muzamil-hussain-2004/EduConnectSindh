# EduConnect Sindh

A smart tutor discovery, verification and online learning platform (pilot: Jamshoro, Sindh).
University of Sindh, Jamshoro: Final Year Project 2026.

## Structure

| Folder | Description |
|---|---|
| `backend/` | Express + TypeScript + PostgreSQL REST API |
| `frontend/` | React app (coming soon) |
| `PROGRESS.md` | Build guide and progress tracker |

## Backend quick start

```bash
cd backend
npm install
npm run dev
```

See [PROGRESS.md](./PROGRESS.md) for the architecture and roadmap.
